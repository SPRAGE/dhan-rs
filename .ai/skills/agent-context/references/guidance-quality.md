# Guidance Quality Checklist

Every finding needs severity, file evidence, impact, and a specific action.

- Commands are exact, runnable in the documented environment, and include required prerequisites.
- Architecture names real entry points, boundaries, generated sources, and non-obvious ordering constraints.
- Always-loaded text changes a likely decision; optional procedures are routed on demand.
- A fact or rule has one authoritative owner rather than copies in adapters and skills.
- Paths, versions, runtime schemas, and active decisions match the repository.
- Customized guidance, secrets, local state, and unrelated work are preserved.
- Generated files have an explicit ownership marker and a safe migration path.
- Claimed token savings include measured static deltas; claimed outcome improvements require representative task evidence.

Prefer deletion or relocation of generic advice, placeholder context, one-off history, obsolete TODOs, and repeated policy. Record durable information before pruning it.
